# legacy/

`PositionTracker.cpp` is the original tracker from December 2025. It was built
inside `C:\OpenHaptics\Developer\3.5.0\examples\HD\console\POSITIONTRACKER` from a
copy of the FrictionlessPlane example, and logged one sample every 5 s through
GLUT's idle loop.

It's kept for reference only and is **not built**. Its replacement is
`apps/position_tracker`. `docs/TROUBLESHOOTING.md` (Part 3) explains the differences.
